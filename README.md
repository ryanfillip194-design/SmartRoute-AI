# SmartRoute AI — Motor Inteligente de Rotas

> **Publicação do pacote acadêmico em preparação.** O código será importado a partir do arquivo `SmartRoute_AI_GITHUB_PRONTO.zip`.

Projeto acadêmico de análise de rotas com frontend web, API Python, SQLite, automação n8n, inteligência artificial local via Ollama, síntese de voz Kokoro (opcional) e notificações Gmail por SMTP.

**O pacote distribuído inclui:** `backend/`, `frontend/`, `n8n/`, `runtime/kokoro/`, `scripts/`, `tests/`, `docs/`, arquivos de configuração de exemplo e scripts de inicialização Windows.

**Proteção dos dados:** o projeto público não precisa de credenciais reais, bancos de dados, logs, tokens, contatos pessoais ou arquivos `.env`. O envio de e-mail real só ocorre mediante configuração e autorização.

## Concluir a importação

No repositório, escolha **Add file → Upload files** e envie o ZIP `SmartRoute_AI_GITHUB_PRONTO.zip` na raiz. A automação `.github/workflows/importar-zip.yml` validará o manifesto SHA-256, extrairá os arquivos sem a pasta externa e removerá o ZIP versionado. Aguarde o resultado da aba **Actions**.

Após a importação, este README provisório será substituído pelo README original, com instruções completas de execução e homologação.
